## Project Overview
This project focuses on analyzing customer and order data to understand order trends, product performance, payment preferences, sales performance, and profitability.

The project follows an end-to-end data analytics workflow, including data cleaning using Python, business analysis using SQL, and interactive dashboard development using Power BI.

The objective is to extract meaningful business insights from customer and order data to support data-driven decision-making.

## Project Workflow
1. Data Cleaning and Preprocessing using Python
2. Business Analysis using SQL
3. Data Visualization and Dashboard Creation using Power BI

## Dataset Information
- **Raw Dataset:** 524 records
- **Cleaned Dataset:** 444 records
- **Raw Data File:** `Ecommerce_Unclean_Project.xlsx`
- **Cleaned Data File:** `Clean_Ecommerce_Project.csv`

The dataset contains order-related information, including products, quantities, sales, discounts, payment modes, order status, and profit.

## Tools & Technologies
- Python
- Pandas
- SQL

## Python – Data Cleaning
Python and Pandas were used to clean and preprocess the raw dataset.

The cleaning process included:
- Handling missing and inconsistent data
- Removing unwanted records
- Standardizing data values
- Preparing the dataset for SQL analysis and Power BI visualization
- Feature engineering for further analysis

The cleaned dataset was exported as a CSV file for further processing.

## SQL – Business Problems Solved
SQL was used to analyze the cleaned dataset and solve business-related questions, including:

- What is the total number of orders?
- What are the total sales?
- Which products are purchased in the highest quantities?
- Which products generate the highest sales?
- Which cities contribute the most to sales?
- What is the monthly sales performance?
- Which products generate the highest profit?
- What are the most commonly used payment modes?
- How many orders have been cancelled?

## Power BI – Dashboard
Power BI was used to create an interactive dashboard to visualize customer and order-related insights.

The dashboard helps analyze:
- Order and sales performance
- Product purchasing trends
- City-wise sales performance
- Payment mode distribution
- Order status and cancellations
- Product profitability
